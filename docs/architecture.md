# Архитектура проекта

Проект разделён на несколько частей:

- `src/auth/` — регистрация и проверка учётных данных;
- `src/payment/` — расчёт суммы платежа;
- `tests/` — автоматические модульные тесты;
- `docs/` — документация.

В учебном примере данные пользователей хранятся в словаре Python. Это упрощённая модель, не предназначенная для промышленного использования.

Тесты позволяют проверить ожидаемое поведение основных функций проекта.
